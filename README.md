# phishing_sim_demo

Since the project we did was based primarily on research and creating a proposal that can go to Texas A&M execs, we just created a demo system to model what a simulated phishing email would look like. With the current resources that we have it wouldn't be able to implement all of the components in a real inbox, so this demo is what we are using to show proof of concept.

To run it locally, just download the code and open it in Chrome. This is just a visual model of the logical flow for what a simulated phishing email should look like, so there are no dependencies required
